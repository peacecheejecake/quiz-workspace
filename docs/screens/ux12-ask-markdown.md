사용자 요청: AI 질문 답변 본문의 표를 렌더링한다. 나머지 Markdown 문법의 지원 여부를 점검하고 빠진 것을 디자인 시스템 스타일로 구현한다.

이 문서는 ASK-01과 AIEXPL-01의 "HTML·링크·이미지는 글자로 다룬다"를 바꾼다. 안전한 링크만 링크가 되고 HTML·이미지는 그대로 글자다. 같은 `AnswerMarkdown`을 쓰는 AI 해설도 함께 바뀐다. DOCSUM-01 요약과 CHNOTE-01 정리 노트는 renderer가 달라서 바뀌지 않는다.

## 규칙

- **허용 목록 parser.** `parseAnswerMarkdown`이 답을 데이터로 바꾸고 React 요소로만 그린다. `dangerouslySetInnerHTML`을 쓰지 않는다. 목록에 없는 것은 글자로 남는다.
- **지원 문법.** 제목(`#`~`######`, 밑줄 제목), 문단, 강제 줄바꿈(줄 끝 공백 2개, `\`), 굵게, 기울임, 취소선(`~~`), 인라인 코드, 코드 블록(``` · `~~~`), 인용, 순서·비순서·중첩·할 일 목록, 링크, 가로줄, 정렬이 있는 표, backslash escape.
- **글자로 남는 것.** HTML 태그, 이미지 `![](…)`, 안전하지 않은 링크, 참조 링크, 각주 `[^1]`, 수식. 들여쓴 코드 블록은 문단으로 다룬다. 답의 들여쓰기는 대개 코드가 아니기 때문이다. 표 칸의 `<br>`만 줄바꿈이다(QTABLE-01과 같은 규칙).
- **강조는 한글 문장 기준.** `**"정답"**은`처럼 문장 부호 뒤에 조사가 붙어도 굵게다(DOCSUM과 같은 규칙). `snake_case`의 `_`는 강조가 아니고, `10~20`의 `~`는 글자다.
- **각주.** `[n]`(끝난 답)과 `[Sn]`(쓰는 중)은 문단·제목·목록·인용·표·강조 안에서 같은 버튼·칩이다. 코드 안에서는 글자다. `\[1\]`처럼 escape한 것도 글자다. 링크 안의 각주는 글자이고(버튼을 링크에 넣지 않는다), `[1](https://…)`은 링크가 아니라 각주다.
- **링크.** `http`·`https`만, 사용자 정보(`user@`)가 없는 URL만 링크다. 나머지는 원문 글자로 남는다. 새 탭으로 열고 `rel="noopener noreferrer nofollow"`, 접근성 이름에 "(새 탭에서 열림)"이 들어간다. 글에 쓴 URL(`https://…`, `<https://…>`)도 링크이며 한글이 이어지면 거기서 끝난다.
- **표.** semantic `<table>`, 첫 줄은 `th scope="col"`이고 칸 수가 모자란 줄은 채운다. 표는 focus를 받는 스크롤 영역(`role="group"`, 이름 `표`) 안에 있어 375px에서 페이지가 넘치지 않는다. 코드 블록도 같다(이름 `코드`).
- **제목 순서.** 답의 제목은 화면의 제목 순서를 깨지 않는다. AI 질문은 `h3`부터, AI 해설 완료 본문은 `h5`부터(쓰는 중은 `h4`부터) 시작하고 앞 제목보다 두 단계 이상 내려가지 않으며 `h6`이 끝이다. 크기는 원문 단계가 아니라 이 수준을 따른다.
- **쓰는 중.** 도착한 글자를 그때마다 그린다. 닫히지 않은 굵게·기울임·취소선·인라인 코드·코드 블록은 닫힌 것처럼 보인다. 머리글 줄만 온 표는 구분 줄이 올 때까지 그리지 않고, 표가 되면 줄을 늘리며 그린다. 표 끝 줄의 칸이 모자라면 채운다. 줄 머리의 미완성 표시(`-`, `1.`, `##`, `- [`)와 끝의 미완성 `[S1`은 다음 글자가 올 때까지 숨긴다. `[글](https://…`는 글만 보인다. `done`이 오면 검증된 답으로 바꾼다.
- **저장 텍스트.** 인용 검증(C04)은 들여쓰기, 코드 블록 안의 공백, 줄 끝 공백 2개를 지운 글에서 끝나면 안 된다. 중첩 목록이 평평해지기 때문이다. 공백 정리는 그 밖의 글자에만 한다.
- **fake.** `E2E-ASK-MARKDOWN`은 합성 Markdown 답을 흘린다(ASK-01-C11). `E2E-ASK-SLOW`와 함께 쓰면 40덩어리로 느리게 흘린다.

## 수용 기준

### UX12-ASKMD-AC01

- **Given:** 375px 폭에서 `E2E-ASK-MARKDOWN` 질문의 끝난 답
- **When:** 넓은 표를 Tab으로 focus해 키보드로 가로 스크롤한다
- **Then:** 표는 `table`이고 머리글은 `columnheader`다. 왼쪽·가운데·오른쪽 정렬이 칸에 적용된다. 표 칸의 각주 버튼이 "본문 발췌" panel을 연다. 표 영역 안에서만 가로 스크롤되고 panel과 페이지는 넘치지 않는다.

### UX12-ASKMD-AC02

- **Given:** 같은 답
- **When:** 본문을 읽는다
- **Then:** 제목은 `h3`·`h4`이고, 굵게·기울임·취소선·인라인 코드·코드 블록·인용·가로줄·중첩 목록·할 일 목록·http 링크가 각 요소로 보인다. 목록과 인용 안의 각주도 버튼이다. `<script>` 글자, 이미지 문법, `javascript:` 링크는 글자로 남고 `img`나 그 링크는 없다.

### UX12-ASKMD-AC03

- **Given:** `E2E-ASK-MARKDOWN`과 `E2E-ASK-SLOW`를 함께 쓴 질문
- **When:** 답을 쓰는 중에 본다
- **Then:** 표가 나타나면 쓰는 중에도 `table`이고 구분 줄(`---`)과 `**`는 글자로 보이지 않으며 페이지 오류가 없다. 끝나면 칩이 각주 버튼으로 바뀌고 같은 표가 남는다.

### UX12-ASKMD-AC04

- **Given:** 끝난 답이 있는 대화
- **When:** light·dark 테마에서 axe로 검사한다
- **Then:** 위반이 없다(`heading-order`, `scrollable-region-focusable`, 색 대비 포함).
