# UX12-FILTER — 홈 검색·필터 줄

**상태:** 구현 중 · [UX12 계획](../implementation/ux12/index.md) · [QOV-01](questions-overview.md) · [SEARCH-01](search.md)
**Route:** `/workspaces/:workspaceId`
**테스트:** `tests/e2e/quality/ux12-home-filter.spec.ts`
**Phase:** UX12-FILTER.0

사용자 피드백(2026-11-06): "문서-풀기-... 라인 하단에 검색(기존 검색 아이콘과 동일)-필터(아이콘) 라인 추가. 검색 누르면 간격이 옆으로 벌어지며 검색창 나타남 + 검색 버튼은 왼쪽 화살표(몸통 없이 촉 부분만 있는, 버튼 테두리 없음) 모양이 됨 — transition: 간격 변화, 스르르 사라지기/나타나기. 필터 버튼은 툴팁 on/off, 타입 필터가 툴팁 안으로, 모바일에서 툴팁 width 100%. 검색창 하단 챕터, 유형 레이블은 삭제. 필터 - 다시 풀기만, 필터 초기화 버튼 삭제." 결정 D-7: 필터 popover에는 챕터와 유형을 넣고 상태 칩은 페이지에 남긴다. 검색을 닫으면 검색어를 지운다.

**줄 구성:** sticky 상단 줄([UX12-HEADER](ux12-home-header.md)) 아래 `[검색][필터]`. 이 줄은 sticky가 아니다.

- **검색 버튼:** 닫힌 상태는 접근성 이름 `검색`, 기존 `SearchIcon`, 경계가 있는 아이콘 버튼이다. 열린 상태는 접근성 이름 `검색 닫기`, 몸통 없는 왼쪽 화살표(`ChevronLeftIcon`), 경계 없는 ghost 아이콘 버튼이다. 두 상태 모두 `aria-expanded`와 `aria-controls`로 입력란 영역을 가리킨다.
- **검색창:** 검색 버튼과 필터 버튼 사이의 칸이 `grid-template-columns` `0fr → 1fr`로 벌어지고 불투명도가 함께 바뀐다. 닫힌 입력란은 `inert`다. `prefers-reduced-motion: reduce`이면 전환 없이 바로 바뀐다. 입력 동작은 SEARCH-01-AC12 그대로다.
- **필터 버튼:** 접근성 이름 `필터`, `FilterIcon`. 누를 때마다 kit `Popover`(이름 `필터`)가 열리고 닫힌다. 안에는 챕터·유형 Select만 있고 레이블 글자는 보이지 않되 접근성 이름은 유지한다. 필터는 닫혀 있으면 값이 보이지 않으므로, 챕터나 유형이 걸려 있으면 버튼에 점 표시와 접근성 설명 `필터 적용 중`을 둔다.
- **상태 칩:** 상태 칩과 `즐겨찾기만`은 페이지에 남는다. `다시 풀기만`과 `필터 초기화` 칩은 없다. `다시 풀기` 상태 칩이 같은 값이다. 예전 주소의 `?retry=true`는 `status=retry`로, `?retry=false`는 그 상태를 뺀 선택으로 읽는다. 범위 picker의 칩은 이 범위가 아니다.
- **빈 결과:** 필터 때문에 결과가 없으면 빈 상태의 `필터 초기화`는 유지한다. 없으면 빈 Heatmap에서 빠져나갈 길이 없다.

## 수용 기준

### UX12-FILTER-AC01

홈 상단 줄 바로 아래에 `검색`과 `필터` 아이콘 버튼이 이 순서로 나란히 있고, 입력란은 닫혀 있어 보이지도 focus되지도 않는다. 페이지에 챕터·유형 Select와 그 레이블, `다시 풀기만`, `필터 초기화`는 없고 상태 칩과 `즐겨찾기만`은 그대로 보인다.

### UX12-FILTER-AC02

`검색`을 마우스나 키보드로 누르면 입력란이 두 버튼 사이에 벌어지며 나타나 focus를 받고, 필터 버튼은 오른쪽으로 밀려난다. 버튼은 경계 없는 `검색 닫기`가 되고 `aria-expanded="true"`다. 칸 너비와 불투명도는 전환으로 바뀐다. 입력하면 Heatmap이 걸러진다.

### UX12-FILTER-AC03

`검색 닫기`를 누르면 검색어와 URL `q`가 지워지고 Heatmap이 전체로 돌아오며, 입력란은 `inert`가 되고 focus는 버튼으로 돌아온다. 입력이 멈추기 전에 닫아도 검색어가 나중에 적용되지 않는다.

### UX12-FILTER-AC04

주소에 `q`가 있으면 검색창이 열린 채 시작하고 그 검색어를 보인다. 닫힌 검색창으로 `q`가 있는 기록 항목에 돌아와도 검색창이 열린다.

### UX12-FILTER-AC05

확정 문제가 없으면 `검색` 버튼은 비활성이고 `QUESTION_SEARCH_BLOCKED` 문구가 버튼의 설명으로 연결된 채 계속 보인다.

### UX12-FILTER-AC06

`필터`를 누르면 popover가 열리고 다시 누르면 닫히며 focus는 버튼에 남는다. 안의 챕터·유형 Select는 레이블 글자가 보이지 않지만 접근성 이름이 `챕터`·`유형`이다. 값을 고르면 Heatmap이 걸러지고, popover를 닫아도 버튼의 점 표시와 설명 `필터 적용 중`이 남는다. 두 값을 전체로 되돌리면 표시가 사라진다.

### UX12-FILTER-AC07

폭 768px 미만에서 필터 popover 폭은 뷰포트에서 페이지 좌우 여백을 뺀 값이고 화면 밖으로 나가지 않는다.

### UX12-FILTER-AC08

`prefers-reduced-motion: reduce`에서는 검색창이 전환 없이 바로 열리고 닫힌다.

### UX12-FILTER-AC09

필터나 검색어로 결과가 0건이면 빈 상태에 `필터 초기화`가 있고, 누르면 검색어·챕터·유형·상태 필터가 모두 풀려 Heatmap이 돌아온다.

### UX12-FILTER-AC10

`?retry=true`로 들어오면 `다시 풀기` 상태 칩만 눌린 상태로 그 문제만 보이고, 다음 필터 변경부터 주소에는 `retry` 대신 `status`가 쓰인다.
