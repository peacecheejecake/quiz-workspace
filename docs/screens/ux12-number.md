# UX12-NUMBER — 교재 문제 번호 우선

**상태:** 구현 중 · [UX12 계획](../implementation/ux12/index.md) · [QOV-01](questions-overview.md) · [QVIEW-01](question-viewer.md)
**Route:** `/workspaces/:workspaceId`
**테스트:** `tests/e2e/questions/ux12-number.spec.ts`
**Phase:** UX12-NUMBER.0

사용자 요청 "챕터 상관 없이 교재의 문제 번호 우선". 결정(D-11 기본값, 2026-11-06): 번호 글자에서 장 접두어와 위치 대체 번호를 뺀다. 번호는 교재에 인쇄된 `questions.question_number`다. 장 묶음과 순서(장 → `sort_order` → 번호)는 그대로다.

- **보이는 글자:** Heatmap 미리보기, 풀이 panel 제목, 범위 고르기 문제 행, 풀이 단계 제목, 결과 목록은 번호만 보인다(`12번`, 제목은 `12번 문제`). 장은 Heatmap·범위 고르기의 장 묶음과 panel 설명, 미리보기의 장 제목 줄이 알려 준다.
- **번호가 없는 문제:** `번호 없음`으로 표시한다. 장 안 위치를 번호처럼 쓰지 않는다.
- **dot 접근성 이름:** 교재 번호는 장마다 다시 시작하므로 dot 이름에는 장을 남긴다: `3장 12번 문제, 객관식, …`, 번호가 없으면 `3장 번호 없음, 객관식, …`. 번호 없는 문제가 한 장에 여럿이고 유형·상태도 같으면 dot 이름이 같다.
- **모의고사:** `문제 k`를 그대로 쓴다.
- **정리 노트·하이라이트:** 각주(`[^1] 12번`), 각주 미리보기, `내 하이라이트`의 출처도 번호만 보인다. 노트 안에서는 장이 자명하다. 각주 글자는 읽을 때 문제의 지금 번호로 다시 계산하므로 이전 노트도 같게 보이고 data migration은 없다. 문제 행이 아예 없으면 저장된 글자(`3장 12번`)가 그대로 보인다.
- **장을 남기는 곳:** 모의고사 문제의 출처 글자(`3장 12번`, MOCK-01)와 AI 질문 첨부 칩(`3장 12번 · …`, ASK-01)은 장을 유지한다. 두 목록에는 장 묶음이 없다.

### UX12-NUMBER-AC01

두 장에 같은 번호의 문제가 있으면 Heatmap은 장 순서대로 묶어 보인다. 미리보기와 풀이 panel 제목은 `1번 문제`만 보이고 장 접두어가 없으며, 미리보기의 장 제목 줄과 panel 설명이 장을 알려 준다. 두 dot의 접근성 이름은 `1장 1번 문제`와 `2장 1번 문제`로 서로 다르다.

### UX12-NUMBER-AC02

범위 고르기의 문제 행은 `1번 · <발문 앞부분> · <유형>`이고 풀이 단계 제목은 `1번`이다. 장 접두어는 없고 행은 그 장의 묶음 안에 있다.

### UX12-NUMBER-AC03

번호가 없는 문제는 미리보기, 풀이 panel 제목, 범위 고르기 행, 풀이 단계 제목, 결과 목록에서 `번호 없음`으로 보이고 위치 번호(`1번`, `문제 1`)로 보이지 않는다. dot 접근성 이름은 `<장> 번호 없음, …`이다.
