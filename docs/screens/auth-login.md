# AUTH-01 — 로그인

**상태:** 확정 화면 요구사항 v1.3 · 2026-10-16 (CAPTCHA AC 추가 · A4 · 2026-10-18)
**Route:** `/login`
**연계 E2E:** `tests/e2e/auth/login.spec.ts`

## 목적·레이아웃
- Next.js App Router 기반, 모바일/데스크톱 반응형 레이아웃과 Minimal Glass 디자인 시스템을 사용한다.
- 상태: 최초 로딩, 입력 검증, 처리 중, 성공, 실패, 빈 데이터, 권한 오류, 세션 만료를 명시적으로 처리한다.
- 입력 컴포넌트에 필수 라벨·설명·에러를 연결하고 키보드와 스크린리더에 대한 접근성을 보장한다.
- Supabase Auth를 사용하되 인증 경계와 리소스 인가는 FastAPI가 재검증한다.

## 수용 기준

### AUTH-01-AC01

- **Given:** 보호 URL에 비로그인 접근
- **When:** 해당 조작·라우트 접근 또는 서버 API 요청
- **Then:** 보호 URL에 비로그인 접근 시 /login으로 이동하고 안전한 상대 경로 next를 유지한다.

### AUTH-01-AC02

- **Given:** 이메일 인증 완료 사용자가 올바른 정보로 로그인하면 원래 Workspace로 이동하며 본인 데이터만 표시한다.
- **When:** 해당 조작·라우트 접근 또는 서버 API 요청
- **Then:** 이메일 인증 완료 사용자가 올바른 정보로 로그인하면 원래 Workspace로 이동하며 본인 데이터만 표시한다.

### AUTH-01-AC03

- **Given:** 잘못된 로그인 정보 입력
- **When:** 해당 조작·라우트 접근 또는 서버 API 요청
- **Then:** 잘못된 로그인 정보 입력 시 민감정보 노출 없이 오류·재시도 UI를 표시한다.

### AUTH-01-AC04

- **Given:** 로그아웃 후 새로고침·보호 경로 직접 접근
- **When:** 해당 조작·라우트 접근 또는 서버 API 요청
- **Then:** 로그아웃 후 새로고침·보호 경로 직접 접근 시 로그인 화면으로 돌아간다.

### AUTH-01-AC05

- **Given:** CAPTCHA가 켜진 환경(`NEXT_PUBLIC_TURNSTILE_SITE_KEY` 설정, docs/auth.md §5.1)에서 로그인 폼을 연다
- **When:** 보안 확인(Turnstile) 토큰이 발급되기 전에 제출하고, 토큰 발급 후 다시 제출하며, 그 뒤 한 번 더 제출한다
- **Then:** 폼에 "보안 확인" 영역이 표시되고, 토큰 전에는 제출 버튼이 `aria-disabled`이며 제출해도 Auth 요청 없이 사유("보안 확인을 완료하면 …")를 표시한다. 토큰 발급 후 로그인 요청(Server Action → `signInWithPassword`의 `options.captchaToken`)에 토큰이 함께 전달된다. 요청이 끝나면(성공·실패 무관) 위젯이 초기화되어 같은 토큰을 다시 보내지 않고, 다음 제출은 새 토큰을 기다린다.

### AUTH-01-AC06

- **Given:** CAPTCHA가 켜진 환경에서 로그인 폼의 보안 확인이 실패·만료되거나 위젯을 불러오지 못했거나, Auth 서버가 토큰을 거부(`captcha_failed`)한다
- **When:** 사용자가 키보드만으로 폼을 조작한다(prefers-reduced-motion: reduce)
- **Then:** 원인 코드·계정 존재 여부 없이 한국어 안내(실패 / 시간 초과 / 불러오기 실패 / 서버 거부)를 텍스트로 표시하고 `role="status"` 또는 form 오류로 스크린리더에 알린다. 키보드로 도달 가능한 "보안 확인 다시 하기"로 위젯을 초기화해 새 토큰을 받은 뒤 다시 제출할 수 있다. 보안 확인 영역의 표시는 애니메이션 없이 동작한다.

## E2E-first 구현 규칙
- 해당 AC ID를 Playwright 시나리오로 먼저 작성하고 기대된 RED 실패를 확인한 뒤 구현한다.
- 성공/실패/권한 차단 결과는 실제 서버 응답에서도 보장되어야 하며 화면 조건만으로 대체하지 않는다.
